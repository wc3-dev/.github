# wc3-dev

An open toolchain for making Warcraft III maps without the World Editor.

The goal is that you can build a whole map without ever opening the World Editor, a 1-to-1 or better replacement for each of its tools.

Website: [wc3.dev](https://wc3.dev)

Moonwell is a C# framework for Warcraft III maps. You write your map's code and object data in C#, and Moonwell
builds the map.

- [moonwell](https://github.com/wc3-dev/moonwell): the framework, build and analyzers
- [moonwell-editor](https://github.com/wc3-dev/moonwell-editor): the editor
- [www](https://github.com/wc3-dev/www): the website, docs and tutorials
